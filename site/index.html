3 · Statistics — what is defensible

3.1 Loop-equipped comparison: statistically indistinguishable

Discordant pairs 2 vs 3 (pipeline-only wins: bugfix-08, feature-08; API-only wins: refactor-01, refactor-11, refactor-12) — exact McNemar p ≈ 1.0. The measured, defensible claim:

"statistically indistinguishable from a frontier API on this suite under an identical loop protocol (47 vs 48), at zero marginal cost and zero data egress."

Source: docs/parity-report-phase1.md @ 8c7a7a3 Addendum 5.

3.2 pass@1 comparison: honest, and significant

Pipeline pass@1 41/50 vs API single-shot 48/50 — exact McNemar p = 0.016 (discordant b=7, c=0): a significant gap at n=50, not inside noise. p ≈ 1.0 applies ONLY to the loop-equipped comparison in 3.1 — never to this one.

Source: §2.1 — docs/four-number-proof.md @ 694eff7 + docs/parity-report-phase1.md @ 8c7a7a3 Addendum 4 item 3 (reviewer-approved amendment, branch wt/amended-pass1). API single-shot 48/50: benchmarks/results/baseline-deepseek-v4-pro-20260807-001937.json @ e9fb21e.

3.3 Retry-loop mechanism

The loop is worth +6 (41 → 47) to the pipeline vs +2 (46 → 48) to the API — the frontier model is already near its ceiling at pass@1, while smaller specialists have headroom that feedback loops capture. Source: docs/parity-report-phase1.md @ 8c7a7a3 Addendum 5.

4 · Honest limitations

  • Hardware floor (G1.5) — open item. The hardware-floor numbers (rented G1.5, T4 tier) are NOT yet measured on rented hardware; this page makes no hardware claim and shows no placeholder or invented specs. See roadmap gate 3 (docs/roadmap-to-revenue.md @ 3bea626).
  • Suite scope: swapos-v1 is single-file Python tasks only (interview-canon, one file per task, self-contained), n = 50, with one baseline vendor (deepseek-v4-pro). The suite is a screening instrument, not a general validator — expand vendors and task classes before generalizing.
  • pass@1 is a real gap: the pipeline needs its retry loop to reach parity (3.2); the headline parity claim is the loop-equipped comparison (3.1).
  • Cost framing — sovereignty only: API runs measured $0.25–$0.45 per suite; pipeline runs locally with zero marginal API cost and zero data egress. No "1/50th cost" or any other cost-ratio claim is made anywhere on this page (retracted red line, docs/roadmap-to-revenue.md @ 3bea626).
  • Sacred evidence: every figure above is parsed from a committed results JSON or quoted from the cited documents (table 5); the grader and suite are never modified to make results pass — any change to suite or grader invalidates the comparison (docs/methodology-standard.md §§1–2).
