# Task: most_common_word

Implement `most_common_word(text)` in `solution.py`.

Given a string, return the most frequently occurring word. Ties are broken by first occurrence. Comparison is case-insensitive; punctuation is not part of a word.

Examples:

- `most_common_word("the cat and the dog")` -> `"the"`
- `most_common_word("one two two three")` -> `"two"`
- `most_common_word("Apple apple")` -> `"apple"`
- `most_common_word("")` -> `None`

Do not change the function signature. Do not add prints.
