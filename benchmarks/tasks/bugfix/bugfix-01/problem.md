# Task: is_palindrome

Implement `is_palindrome(s)` in `solution.py`.

Given a string `s`, return `True` if it reads the same forwards and backwards
after ignoring letter case and any character that is not a letter or digit
(spaces, punctuation, and symbols are ignored). The empty string is a
palindrome.

Examples:

- `is_palindrome("racecar")` -> `True`
- `is_palindrome("Racecar")` -> `True`
- `is_palindrome("A man, a plan, a canal: Panama")` -> `True`
- `is_palindrome("hello")` -> `False`
- `is_palindrome("12321")` -> `True`
- `is_palindrome("")` -> `True`

Do not change the function signature. Do not add prints.
