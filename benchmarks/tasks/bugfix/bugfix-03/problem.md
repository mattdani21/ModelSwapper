# Task: count_vowels

Implement `count_vowels(s)` in `solution.py`.

Given a string, return the number of vowels in it. The vowels are
`a`, `e`, `i`, `o`, and `u`; counting is case-insensitive.

Examples:

- `count_vowels("hello")` -> `2`
- `count_vowels("HELLO")` -> `2`
- `count_vowels("aeiou")` -> `5`
- `count_vowels("xyz")` -> `0`
- `count_vowels("")` -> `0`

Do not change the function signature. Do not add prints.
