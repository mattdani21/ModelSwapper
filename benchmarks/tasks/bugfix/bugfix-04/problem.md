# Task: factorial

Implement `factorial(n)` in `solution.py`.

Given a non-negative integer `n`, return `n!` (the product of all integers
from 1 to `n`). By convention `0! == 1`.

Examples:

- `factorial(0)` -> `1`
- `factorial(1)` -> `1`
- `factorial(5)` -> `120`
- `factorial(10)` -> `3628800`

Do not change the function signature. Do not add prints.
