# Task: reverse_list

Implement `reverse_list(lst)` in `solution.py`.

Given a list, return a **new** list containing the same elements in reverse
order. The original list must not be modified.

Examples:

- `reverse_list([1, 2, 3])` -> `[3, 2, 1]`
- `reverse_list([])` -> `[]`
- `reverse_list([7])` -> `[7]`

Do not change the function signature. Do not add prints.
