# Task: longest_unique_substring

Implement `longest_unique_substring(s)` in `solution.py`.

Given a string, return the length of the longest substring that contains no
repeating characters.

Examples:

- `longest_unique_substring("abcabcbb")` -> `3`
- `longest_unique_substring("bbbbb")` -> `1`
- `longest_unique_substring("pwwkew")` -> `3`
- `longest_unique_substring("abba")` -> `2`
- `longest_unique_substring("")` -> `0`
- `longest_unique_substring("abcdef")` -> `6`

Do not change the function signature. Do not add prints.
