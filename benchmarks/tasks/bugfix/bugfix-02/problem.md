# Task: sum_even_numbers

Implement `sum_even_numbers(nums)` in `solution.py`.

Given a list of integers, return the sum of all even numbers in the list.
An empty list sums to 0.

Examples:

- `sum_even_numbers([1, 2, 3, 4])` -> `6`
- `sum_even_numbers([2, 4, 6])` -> `12`
- `sum_even_numbers([1, 3, 5])` -> `0`
- `sum_even_numbers([])` -> `0`
- `sum_even_numbers([-2, 3, -4])` -> `-6`

Do not change the function signature. Do not add prints.
